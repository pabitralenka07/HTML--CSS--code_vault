A modern, comprehensive repository and interactive showcase of **140+ HTML and CSS projects**, practice files, playable games, frontend tasks, UI components, and cheatsheets.

---

## ✨ Features

- **📱 Interactive Device Simulator**: Test and preview any of the 140+ projects inside simulated device viewports (Desktop, Tablet / iPad 768px, Mobile / iPhone 375px) with orientation rotation!
- **⚡ Instant Fuzzy Search & Tag Filtering**: Search projects by name, technology, or tag (`#Game`, `#JavaScript`, `#Canvas`, `#Animation`, `#Forms`, `#Tables`).
- **🎨 Curated Modern UI**: Sleek dark and light modes with smooth transitions and glassmorphism styling.
- **💻 Integrated Source Code Inspector**: Inspect full HTML and CSS source code with one-click copy to clipboard.
- **❤️ Favorites & Bookmarks**: Save preferred demos directly in browser storage.
- **🚀 Zero Dependencies & Ultra-Fast**: Built with pure semantic HTML5, CSS3, and vanilla JavaScript for blazing performance on any device.

---

## 📁 Repository Structure

- [**`HTML Practice/`**](./HTML%20Practice) - Fundamental to advanced HTML exercises covering input elements, semantic tags, tables, forms, media, and interactive mini-projects (Drive Mad 3D Game, Tic Tac Toe Multiplayer).
- [**`CSS/`**](./CSS) - Styling demonstrations, responsive layouts, and reusable UI components (13 Logins, 8 Cards, 7 Navbars, 7 Sidebars, 11 Footers, Dropdowns, Menus, and Dashboards).
- [**`FRONTEND TASKS/`**](./FRONTEND%20TASKS) - Practical frontend challenges and real-world templates including landing pages, timetables, ID cards, forms, and calculators.
- [**`Prime_practice/`**](./Prime_practice) - Focused practice modules on tables and form designs.
- [**`html-css-cheat-sheet-master/`**](./html-css-cheat-sheet-master) - Quick-reference cheat sheets, animation demos, and tooling guides for modern web styling.

## 🛠️ Getting Started

1. **Visit the Live Site**:
   Explore all 140+ projects directly at [https://html-css-code-vault.vercel.app](https://html-css-code-vault.vercel.app).

2. **Run Locally**:
   ```bash
   git clone https://github.com/pabitralenka07/HTML--CSS--code_vault.git
   cd HTML--CSS--code_vault
   # Open index.html directly in your browser or with VS Code Live Server
   ```

3. **Deploy to Vercel**:
   ```bash
   npx vercel --name html-css-code-vault --prod --yes
   ```
